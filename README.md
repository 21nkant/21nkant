# Hi, I'm Nishi 👋

I'm an AI / software engineer in New York. At [Sanveo](https://sanveo.com) I build production LLM and agent systems for construction and engineering teams, and I take them from client discovery through deployment, CI/CD, and telemetry.

Most of my work happens where language models meet real engineering data: agents that call typed tools, return structured outputs, and check their own work before a person approves anything.

## What I'm building

- **Setuva**: an AI agent that works inside Autodesk Revit for electrical engineers, which I'm co-building with [@KAUSSHIK](https://github.com/KAUSSHIK) and [@rishihk](https://github.com/rishihk). It reads the live model, proposes typed changes with citations, and writes nothing until an engineer approves. ([setuva.ai](https://setuva.ai))
- **Maango**: a registry of what websites allow AI agents to do, covering 1M+ domains. I co-built it with a small team and wrote the agent-facing and publisher-facing integrations: an MCP server, a Python SDK, a WordPress plugin, and a Shopify app.
